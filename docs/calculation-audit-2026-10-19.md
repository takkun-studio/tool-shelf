# 計算ロジック監査 2026-10-19

対象: 公開10ツール + draft 30ツール、合計40件。

## 判定

- PASS: 数式の意味が明確で、現行または予定式で計算可能。
- WARN: 数式自体は作れるが、入力定義・用語・前提が不足しており、そのまま実装すると誤解や誤計算につながる。
- BLOCK: 現在の入力項目または式では正しい結果を出せない。実装前に仕様修正が必要。

集計: PASS 25 / WARN 9 / BLOCK 6。

## 全体で先に直すべき入力仕様

現行 `src/lib/validation.ts` は金額・数量・%をすべて整数だけ受け付ける。計算関数自体は小数を扱えるが、画面からは入力できない。

これは次の用途で実害が出る。

- 決済手数料 3.6% などの小数率
- 源泉徴収 10.21% などの小数率
- 作業時間 2.5時間、0.25時間など
- 比較シミュレーションの細かい率

draft群を実装する前に、少なくとも「小数可の割合」「小数可の時間」をField仕様へ追加する。

| 1 | 原価・利益計算 | PASS | 利益=売価-原価-送料-手数料-その他。損益ゼロ売価も正しい。手数料率が小数入力できない点はUI側の問題。 |

| 3 | マルシェ出店収支計算 | PASS | 売上、決済手数料、固定費、限界利益、損益分岐個数の式は整合。決済率の小数入力だけ要改善。 |
| 4 | 値引き・セール利益計算 | PASS | 値引後売価、手数料、利益、赤字回避売価は整合。率の小数入力だけ要改善。 |
| 5 | 手取り売上計算 | PASS | 販売手数料+決済手数料を売価に掛ける前提では正しい。プラットフォーム別に基準額が違う場合は個別プリセットで吸収する。 |
| 6 | サービス料金設計 | PASS | 目標時給×作業時間+経費。正しい。2.5時間等を入れられるよう時間入力は小数対応が必要。 |

| 8 | 在庫回転・仕入れ資金計算 | PASS | 在庫金額=在庫数×原価、持ち月数=在庫数/月販数。正しい。 |
| 9 | 販売チャネル比較計算 | PASS | 同じ基準の販売手数料・決済手数料を売価に掛ける比較として正しい。率の小数入力だけ要改善。 |
| 10 | 初期投資回収計算 | PASS | 回収件数=ceil(初期費用/1件利益)、回収月数=回収件数/月間件数。離散販売数として妥当。 |

### 公開10ツールの追加独立テスト例

- 原価・利益: 売価2570、原価913、送料210、手数料7.5%、固定40、その他87 → 手数料232.75、利益1127.25、損益ゼロ売価1352。
- 損益分岐: 売価850、変動費330、固定費3500 → 限界利益520、必要7個、損益分岐売上5950。
- マルシェ: 売価1200×13個、原価420、固定費3200、キャッシュレス60%、決済3.6% → 決済手数料336.96、最終利益6603.04、損益分岐5個。
- 値引き: 通常3500、12.5%引、原価1200、送料450、手数料8.8%、固定30、その他70 → セール価格3062.5、利益1043、赤字回避売価1919。
- 手取り: 売価5200、販売6.6%、決済3.6%、原価1400、送料600、その他150 → 手数料530.4、手取り4669.6、利益2519.6。
- サービス: 時給2800×2.5時間+経費860 → 7860。
- 月次目標: 目標利益12000、1件限界利益725、固定4000、単価1800 → 必要23件、必要売上41400。
- 在庫: 17個×原価430、月販6 → 在庫金額7310、2.8333か月。
- チャネル: A利益2104.8、B利益2231.4 → A-B=-126.6。
- 初期投資: 初期125000、1件4300、月12件 → 30件、2.5か月。

| 17 | 税引後ほんまに残る額 | PASS | 利益=売上-経費、取り置き=利益×設定率、残額=利益-取り置き。名称は「税引後」より「税取り置き後」の方が正確。 |
| 18 | インボイス影響ざっくり計算 | BLOCK | 売上・対象割合・税率だけではインボイス影響は計算不能。仕入額、相手の登録状況、仕入税額控除割合、期間等が必要。 |
| 19 | 経費使いすぎ警報 | PASS | 経費率=経費/売上×100。売上0の時は計算不能表示。警報閾値はユーザー設定。 |

## 税務系の一次情報で確認した事項

- 報酬・料金の源泉徴収は対象種類で計算方法が異なる。原稿料・デザイン料等の一般例では100万円以下部分10.21%、100万円超部分20.42%。
- 家事関連費は、業務に直接必要な部分を使用時間・床面積等の合理的基準で区分できる範囲が必要経費。
- 2026-04-01以後、一定の青色申告者の少額減価償却資産特例は10万円以上40万円未満、年間合計300万円まで等の要件がある。
- 免税事業者等からの課税仕入れに係るインボイス経過措置は、2026-10-01から2029-09-30まで50%控除の期間。
- 消費税は標準10%、軽減8%があるため、税込・税抜変換は税率を固定しない。

## 実装前ゲート

draftをpublishedへ移す条件:

1. 式をこの監査表に固定。
2. 通常値テストを1件以上。
3. 0・100%・分母0・利益0など境界値テスト。
4. 金額丸め/個数切り上げのルールを固定。
5. 税務制度値を使うものは一次情報の日付と根拠を記録。
6. WARN/BLOCKのまま公開registryへ入れない。
